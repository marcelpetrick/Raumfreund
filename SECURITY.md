# Security policy

Please report vulnerabilities privately through GitHub's **Security → Report a
vulnerability** flow for this repository. Do not include captured audio,
keystores, signing passwords or other personal data in a report.

Only the latest published release is supported. Reports affecting microphone
privacy, unintended storage/transmission, permission handling, release signing
or artifact integrity receive priority. Public issues are appropriate for
ordinary non-sensitive defects.
